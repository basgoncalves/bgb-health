| File | What it is |
|---|---|
| `01_guidelines_review.md` | Evidence review: current training and nutrition recommendations by client goal, red flags, supplements, references |

Review both files once a year, or when a major guideline changes (WHO, ACSM, ISSN, IOC, Austrian recommendations).
